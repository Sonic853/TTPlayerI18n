# 可选 gettext 国际化

播放器从 EXE 同目录动态加载 `ttp_i18n.dll`，翻译目录固定为 EXE 同目录的
`i18n`。主程序不导入该 DLL；缺少 DLL、接口不兼容或目录不可读时，继续使用
`ttpres.dll`、EXE 内嵌资源和代码中的默认文本。`ttpres.dll` 仍用于皮肤、菜单、
对话框布局等原有资源，启动时的产品名称校验也仍读取原始字符串。

## 使用

```text
TTPlayerRebuild.exe
ttp_i18n.dll
ttpres.dll
i18n/
  ttplayer.pot
  chs/LC_MESSAGES/ttplayer.po  # 简体中文
  cht/LC_MESSAGES/ttplayer.po  # 繁體中文
  en_US/
    LC_MESSAGES/
      ttplayer.po
      ttplayer.mo         # 可选
```

安装 DLL 后，在主窗口右键菜单的“界面语言”中选择语言，重启播放器生效。
语言文件修改也在重启后加载。菜单提供“自动（系统语言）”“原始文本”和
`i18n` 中有 PO/MO 的语言目录。没有 DLL 时不增加语言菜单。

选择结果保存在 `TTPlayerRebuild.xml` 的 `General` 元素 `Language` 属性中：

```xml
<General Language="en_US" />
```

只修改已有元素的属性，保留其它设置。`auto` 是默认值，选择 Windows 的界面
语言；`source` 禁用翻译。语言标识支持 `en_US` / `en-US`，区域语言缺词时可
继续查询父语言（例如 `en_US` → `en`），然后回退原文。

`zh_CN`、`zh_SG`、`zh-Hans` 对应 `chs`；`zh_TW`、`zh_HK`、`zh_MO`、
`zh-Hant` 对应 `cht`。具体地区和脚本目录优先，其次为简繁别名目录，最后尝试 `zh`。
简繁 PO 已按自建文本、字符串表、菜单及对话框分类，并补齐当前模板。

提供的 `en_US` 是英文示例目录，覆盖部分菜单、通用控件和重建版新增文本，
尚未完成的译文保留原文。完整待翻译条目见 `ttplayer.pot`。

## PO / MO 优先级

对于每个语言目录，先尝试 `LC_MESSAGES/ttplayer.mo`；文件缺失、格式不支持或
损坏时，尝试同名 `.po`。**有效 MO 整体优先于同目录 PO**：MO 中缺少某个词条
时，不混用可能过时的 PO，而是查询父语言及原文。编辑 PO 后，可删除对应 MO，
或重新编译 MO，再重启播放器。

PO 要求 UTF-8，允许 BOM；支持多行字符串、引号/反斜杠/C 转义、`msgctxt`、
`msgid_plural`、`msgstr[n]` 和 `Plural-Forms` 表达式。空译文、`fuzzy` 和 `#~`
废弃条目不参与翻译。MO 支持 revision 0 的大小端文件。文件大小最多 16 MiB、
词条最多 100,000、复数形式最多 16；表达式长度和递归深度也有上限。

如已安装 GNU gettext，可执行：

```powershell
msgfmt --check --check-format -o i18n/en_US/LC_MESSAGES/ttplayer.mo i18n/en_US/LC_MESSAGES/ttplayer.po
```

运行播放器不需要安装 gettext 命令行工具，也不需要 libintl/libiconv DLL。

## 文本接入与回退

`include/ttplayer/i18n/api.h` 是带大小和版本号的 C ABI。DLL 管理只读词典，主程序
通过调用方缓冲区取得 UTF-16 文本，没有跨 CRT 分配/释放字符串的接口。

主程序适配层位于 `src/i18n/i18n.cpp`：

- `ResourceText` 为原版和 EXE 字符串表增加逐条翻译。
- `LoadMenu` 在菜单拆分、动态修改和自绘缓存建立之前翻译菜单层级。
- `DialogTemplate` 生成临时的标准/扩展对话框模板，保留样式、字体、控件 ID、
  图片序号和初始化数据。重复 `IDC_STATIC` 通过 ID 与出现次数区分。
- WTL 模态/非模态对话框和属性页使用这些模板；回调仍收到原来的参数和
  `PROPSHEETPAGE` 信息。`DialogCaption` 同步覆盖选项导航标题。
- `Text` / `Literal` 标记代码中的默认界面文本；`Plural` 支持计数文本。

资源翻译上下文形如 `ttpres/string/128`、`exe/string/4091`、
`ttpres/dialog/200/control/4294967295/3`、`ttpres/menu/138/item/0.0`。
PO/MO 保留上下文和原文组成的 gettext 键。播放器直接读取当前 DLL／EXE 的资源文字，
不再编译 `resource_messages.inc`。DLL 在加载词典时建立资源上下文索引：精确键未命中时，
可按唯一的资源上下文查找译文，支持简繁资源原文差异；存在多个候选原文时回退。
自建文本和复数仍使用精确 gettext 键。资源 ID 或结构变化时需要重新提取并核对上下文。

不要翻译服务器 URL、文件模式、元数据键或用户输入。已有插件服务器资源读取
保持原样。`%d`、`%s`、`%(Title)` 等参数必须保留；普通 printf 参数不得交换类型
或使用当前调用点不支持的位置参数。结构化字符串的 `|`、命令说明换行和文件
过滤模式也必须保留。校验以当前实际资源为准，发现不兼容的译文时，主程序使用该资源原文。
缺失的资源保持为空，不会从翻译文件补造。此实现兼容 ABI v1，旧 DLL 未能匹配的资源也会回退。

原有窗口布局仍使用资源中的尺寸和字体；翻译时需要检查长文本显示。皮肤图片中
画好的文字、第三方插件自建窗口和系统对话框按钮不由这一层翻译。
`MessageBox` 的正文及标题使用同一套翻译，启动依赖错误提示也会读取配置中的语言。
新增显示文本应显式接入上述函数。

## 构建与提取

在包含 `rebuild` 与 `gettext` 的父目录中：

```powershell
cmake -S rebuild -B rebuild/build -G "Visual Studio 18 2026" -A Win32 -DTTPLAYER_BUILD_I18N=ON -DTTPLAYER_STAGE_RUNTIME=OFF
cmake --build rebuild/build --config Release --target ttplayer_rebuild --parallel 4
```

DLL 源码位于用户工作区的独立 `gettext` 目录。可通过
`TTPLAYER_GETTEXT_SOURCE_DIR` 指定其它位置；发现该目录时默认构建 DLL。
仅检出 `rebuild` 仓库、没有该目录时，默认只构建可回退的主程序。
显式开启 `TTPLAYER_BUILD_I18N=ON` 必须提供 DLL 源码。发布脚本会收录构建目录
中已有的 DLL 和 `i18n`；独立仓库 CI 需要额外提供 DLL 源码才能产出 DLL。

普通版和 XP/Win7 版共用同一份 x86 DLL；所有构建方式均使用兼容运行库，并生成
`i18n-legacy-imports.json`。打包脚本检查审计报告和 DLL 哈希一致。
普通版主动加载时先处理 i18n，再加载 `ttpcomm.dll`；兼容版为支持 XP 静态 TLS，
保留 `ttpcomm.dll` 的启动导入，Windows 会在入口函数前加载它。

资源未变化时，复用现有 POT 中的资源词条并扫描代码，更新 POT：

```powershell
python gettext/tools/extract_catalog.py
```

资源变化后，在 Windows 上从资源 DLL 和已编译 EXE 提取：

```powershell
python gettext/tools/extract_catalog.py --ttpres ttpres.dll --exe rebuild/build/Release/TTPlayerRebuild.exe --resource-texts ttpres/chs/texts.json --resource-texts ttpres/cht/texts.json
python gettext/tools/sync_catalogs.py
```

该脚本以数据文件方式读取 PE 资源，同时提取代码中显式标记的字符串；不会执行
资源 DLL。POT 是翻译维护文件，不会编译进播放器或 DLL；构建不依赖原版私有资源。
`--resource-template` 可指定作为输入的 POT，提取工具不会生成主程序文本表。
`--resource-texts` 补充其他版本独有的字符串 ID；同步脚本按资源上下文补全中文空译文，
保留人工修改，维护方法见 [README](../README.md#维护翻译)。

## 验证

启用 `BUILD_TESTING=ON` 后：

```powershell
cmake --build rebuild/build --config Release --target i18n_ui_tests ttp_i18n_catalog_tests
ctest --test-dir rebuild/build -C Release -R "^(i18n_ui_tests|i18n_startup_tests|ttp_i18n_catalog_tests|ttp_i18n_translation_tests)$" --output-on-failure
```

测试覆盖 PO/MO、上下文、复数规则、坏文件与 UTF-8、MO 优先、父语言、无 DLL
与缺词回退、格式参数检查、菜单、标准/扩展对话框、重复静态控件 ID、属性页回调
兼容、语言设置保存、启动弹窗、简繁目录别名、简繁资源 DLL 直接读取及翻译完整性。
测试使用临时目录，不覆盖运行目录的个人语言文件或设置。
